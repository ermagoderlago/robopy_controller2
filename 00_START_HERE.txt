WORKFLOW DI PROGRAMMAZIONE DI MARCUS:
Quando viene richiesto di analizzare, correggere o implementare un modulo o un nodo ROS 2, l'operatore AI DEVE seguire questa pipeline sequenziale:

1) Leggere 'marcus_core_rules.md' per allinearsi sui vincoli hardware e di sopravvivenza globali.
2) Consultare la Mappa dei Domini (Mappa Spoke in marcus_core_rules.md) per identificare il file specifico (es. /docs/lessons/audio_vui_pipeline.md) associato al task. Se il task è cross-dominio, è consentito caricare al massimo due file di lezioni.
3) Utilizzare il tool di lettura per estrarre ESCLUSIVAMENTE il codice sorgente del nodo interessato e il file delle lezioni/ECO identificato. È SEVERAMENTE VIETATO caricare documentazione non pertinente al dominio corrente.
4) Prima di emettere il codice modificato, produrre un blocco di testo prefissato con [COGNITIVE_CHECK] che attesti esplicitamente il rispetto dei vincoli di marcus_core_rules.md applicati al codice che si sta per scrivere.
