WORKFLOW DI PROGRAMMAZIONE DI MARCUS:
Quando viene richiesto di analizzare, correggere o implementare un modulo o un nodo ROS 2, l'operatore AI DEVE seguire questa pipeline sequenziale:

1) Leggere 'marcus_core_rules.md' per allinearsi sui vincoli hardware e di sopravvivenza globali.
2) Consultare la Mappa dei Domini (Mappa Spoke in marcus_core_rules.md) per identificare il file specifico (es. /docs/lessons/audio_vui_pipeline.md) associato al task. Se il task è cross-dominio, è consentito caricare al massimo due file di lezioni.
3) Utilizzare il tool di lettura per estrarre ESCLUSIVAMENTE il codice sorgente del nodo interessato e il file delle lezioni/ECO identificato. È SEVERAMENTE VIETATO caricare documentazione non pertinente al dominio corrente.
4) Prima di emettere il codice modificato, produrre un blocco di testo prefissato con [COGNITIVE_CHECK] che attesti esplicitamente il rispetto dei vincoli di marcus_core_rules.md applicati al codice che si sta per scrivere.
5) Se le modifiche alterano le funzionalità generali, i flussi utente o lo stato di avanzamento del robot, aggiornare la guida globale 'marcus_robot_guide.md'.
6) Ispezionare e aggiornare la DFMEA ('fmea/dfmea.yaml') ed eseguire 'python fmea/calculate_and_report_fmea.py' per ricalcolare i Risk Priority Number.
7) Sincronizzare le modifiche tra PC e Robot tramite './sync_marcus.sh' (recupero autonomo back-sync e hot-swap Python).

🚀 QUICK START & MODALITÀ DI AVVIO OPERATIVE
───────────────────────────────────────────────────────────────────

► MODALITÀ CREA MAPPA (SLAM 3D/2D con RTAB-Map):
    ssh robopy@marcus
    ./restart_hailo.sh --slam    # oppure default ./restart.sh
    # Quando la mappa 2D è completa, salvala in /mnt/ssd/maps/:
    ./scripts/save_map.sh salotto

► MODALITÀ NAVIGA SU MAPPA NOTA (AMCL 2D + Map Server - FM-NAV-030):
    ssh robopy@marcus
    ./restart_hailo.sh --amcl --map=/mnt/ssd/maps/salotto.yaml
    # Zero conflitti TF (RTAB-Map publish_tf: false, ostacoli 2.5D attivi)

► VERIFICA FRAME & GERARCHIA TF (REP-105):
    ros2 run tf2_tools view_frames
    bash tf_verify.sh

Frame standard ROS atteso:
    odom → base_link → camera_link → camera_optical_frame
                    ↘ imu_link
    (in navigazione: map → odom emesso esclusivamente da AMCL o RTAB-Map)
