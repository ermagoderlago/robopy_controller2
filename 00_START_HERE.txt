🚀 QUICK START (3 STEPS):
───────────────────────────────────────────────────────────────────

Step 1: Launch the system
    ros2 launch robopy_controller test_odometry_launch.py

Step 2: Verify frame hierarchy (in another terminal)
    ros2 run tf2_tools view_frames

Step 3: Run automated test
    bash tf_verify.sh

Expected: Frame hierarchy shows:
    odom → base_link → camera_link → camera_optical_frame
                    ↘ imu_link
